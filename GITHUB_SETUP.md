## Command-line publishing

After creating an empty repository on GitHub:

```bash
cd ai-smart-home-assistant
git init
git add .
git commit -m "Initial project repository"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/ai-smart-home-assistant.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.
